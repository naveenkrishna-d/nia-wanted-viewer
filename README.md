# NIA Most Wanted Explorer — automatic refresh edition

Unofficial searchable viewer for public records on the National Investigation Agency (NIA) website.

## What changed

The front-end no longer contains a hard-coded JavaScript list. It loads `data/records.json`, which is regenerated by `scripts/update_nia.py` from the official public NIA pages.

### Automatic refresh

A GitHub Actions workflow in `.github/workflows/update-nia.yml` runs every **6 hours** and can also be run manually.

On each run it:
1. Fetches `https://nia.gov.in/most-wanted` and `https://nia.gov.in/most-wanted-photos` plus paginated pages.
2. Parses public profile fields such as name, aliases, parentage, address, wanted-in case references, age/status, organization, reward and source image URL when available.
3. De-duplicates profiles across the two NIA sections.
4. Validates the result before publishing.
5. Refuses to overwrite the last known good dataset if the scrape is suspiciously small or the source is unavailable.
6. Writes a verification status and a short change log.
7. Commits the refreshed JSON back to the repository.

## Files

- `index.html` — searchable card/table viewer.
- `data/records.json` — currently published dataset.
- `data/status.json` — latest refresh/validation state.
- `data/change_log.json` — latest 100 refresh summaries.
- `scripts/update_nia.py` — source fetcher/parser/validator.
- `.github/workflows/update-nia.yml` — six-hour schedule.
- `requirements.txt` — Python dependencies.

## Recommended deployment: GitHub Pages

1. Create a GitHub repository and upload this folder to the repository root.
2. In **Settings → Pages**, deploy from the `main` branch/root (or use your preferred Pages deployment workflow).
3. In **Settings → Actions → General → Workflow permissions**, allow **Read and write permissions** so the refresh workflow can commit updated JSON.
4. Open **Actions → Refresh NIA public data → Run workflow** once to test it.
5. After the first successful run, the page header will show the newest verification timestamp.

The scheduled workflow then refreshes the data automatically every six hours. If NIA changes its page markup enough to break parsing, the workflow fails and the site keeps serving the previous validated data rather than replacing it with a broken/empty result.

## Run locally

Because the site fetches JSON, serve the folder over HTTP rather than opening `index.html` with `file://`:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

To manually refresh:

```bash
pip install -r requirements.txt
python scripts/update_nia.py
```

## Source and accuracy note

This project is **not affiliated with NIA**. It republishes and reorganizes public information from the official NIA website. The official NIA website remains authoritative. A record being present in a previous dataset must not be treated as proof of current wanted status after a failed refresh; users should verify on the official source.
